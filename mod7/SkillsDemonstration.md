1)   The 3 NP problems that I have picked are Battleship, Sudoku and jigsaw puzzles. These 3 problems are all similar in a way that they are a puzzles that have a set way of being solved and easily verifiable that they are solved correctly. we will start with the easier one the jigsaw puzzle. You have a set number of pieces that have to be arranged in an order where they all interconnect with one another. We can verify that it was done correctly by checking the photos if it comes with one and that it matches, check if there is any missing pieces. That is kind of similar to sudoku puzzles in that you have a grid of numbers and have to fill in the grid of non repeating numbers in each row and column. and to verify it you can check the solution in the back or double check the squares so there is no repeating or empty spaces in the grid. For battleship the rules are to find the location of the battleships on a grid that consist of black cells. each battleship has a set size. the grid is also indicated by numbers on how many cells are occupied in that cell or row. to verify that it is complete you can check if the filled in squares match up with the numbers in the column and rows. These puzzles can all be checked quickly by going over the rules of the puzzles and having an answer aka the solution is a shortcut way into verifying that it is indeed the solution or not. Finding the solution to these problems can take a little bit of time pending on how large the puzzle start out as. if it is a 9x9 or 3x3 or a 10 piece puzzle it wont take that long to find a path towards the solution. The inverse of that is if the puzzles are huge then it is going to take a while to find your footing as there is a lot of possible starting points for a person to chose from, and if it takes a while to get a good starting point it is going to take longer to solve. 

2) Universality is the theory that all computers can solve the same problems. Comparability is the limit on what is possible with what machines can do practically. Intractability is the upper bounds on what is possible for a machine or computer to do, it will complete a problem but it is going to take a long time for it to produce an answer.
