Static methods are methods other than main
1st line in a static method is the signature that is the name and the 2nd part is the parameter variables and return type, bool will return bool, int will win ans string with string. 
signature - return type - method name- arg type - variable
whats inside are local variables and the method body with a return 
can have multiple variables just have to passed from the main or other method 1st or youll get a crash 
overloading is when you have 2 methods with the same name but different variables
can use static methods to organize the code 
can use private or public keywords to be able to access the method in another script or keep it inside 1 script only. 
clients refer to a program that calls a given library method
API- a contract between the client and the implementation that is a clear specification of what the method is to do
implementation - implements the methods in an API, kept by convention in a file with the library name and a .java extension
modular programming we break up each task into smaller, more manageable subtasks, then implement and independently debug code that addresses each subtask
break down programs into smaller sizes, easier to manage and able to use that code for another project 
if you encounter and old program do not touch it. 
recursion is a program calling it self until it hits the base case
dynamic programing - The basic idea is to recursively divide a complex problem into a number of simpler subproblems; store the answer to each of these subproblems; and, ultimately, use the stored answers to solve the original problem
top down - we store or cache the result of each subproblem that we solve, so that the next time we need to solve the same subproblem, we can use the cached values instead of solving the subproblem from scratch
bottom up - we compute solutions to all of the subproblems, starting with the “simplest” subproblems and gradually building up solutions to more and more complicated subproblems
develop code with increments 
solve easier problems 
consider recursion solution 
compile and run often 
can build helper tools
